# Security

## Supported versions

Only the latest release of the skills is supported. The current version is 0.1.0.

## Report a problem

Do not open a public issue for a security problem.

1. Use private vulnerability reporting on this repository. Open the Security tab and choose Report a vulnerability.
2. Or write to info@huntcover.com.

Include which skill file is affected, what an agent could be made to do, and how to repeat it. Never include a real key, a signing secret or customer data. If you find one in this repository, report it the same way.

## What counts

A skill text that could lead an agent to hold, print or log a key, to approve a money movement without a person, to call an endpoint that does not exist, or to follow an instruction hidden in outside content.

## What to expect

Hunt Cover reads every report and answers by email or in the private report. Please give us time to fix the problem before you tell anyone else.
